# 삼국연의 · 난세기 (三國演義 亂世記)

매번 **완전히 새로운 중원**이 생성되는 절차적 삼국지 전략 시뮬레이션.
빌드 도구 없이 정적 파일만으로 동작하며, 그래픽과 음악을 전부 실시간으로 합성한다.

```bash
# 저장소 루트에서
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000/sangokushi/
```

---

## 무엇이 무작위인가

**모든 것.** 미리 만들어 둔 지도도, 정해진 인물도, 고정된 아이템도 없다.

| 요소 | 생성 방식 |
|---|---|
| **대륙** | Perlin 노이즈 + 도메인 워핑으로 해안선을 빚고, 능선 노이즈로 산맥을 얹는다 |
| **하천** | 우선순위 홍수로 웅덩이를 메운 뒤 유량을 누적 — 실제 강처럼 지류가 합류한다 |
| **지형** | 고도·습도·기온의 **분위수**로 분류해 어떤 시드든 균형 잡힌 구성이 나온다 |
| **도시** | 거주 적합도 가중 포아송 배치 → MST + 상대근접그래프로 가도망 연결 |
| **주(州)** | 도시 좌표에 k-means++ 군집화 |
| **인명·지명** | 성씨 100여 개 × 이름 글자 100여 개 × 자(字) 조합, 중복 방지 |
| **무장** | 13종 아키타입 × 능력 정규분포 × 특기 60종 × 성격 15종 × 꿈 14종 × 출신 12종 × 성장형 5종 × 병과 적성 |
| **초상화** | 골격·이목구비·머리·수염·관복 형질을 시드에서 파생해 캔버스로 합성 |
| **보물** | 기본형 40종 × 접두 26종 × 접미 20종 × 희귀도 6단계 × 무작위 옵션 — 사실상 수만 가지 |
| **전장** | 공격받는 성 주변 지형·계절을 읽어 매번 새로 생성 (하천·여울·절벽·성곽·날씨·주야) |
| **사건** | 30여 종의 이벤트가 조건과 가중치에 따라 발생 |

같은 시드를 넣으면 같은 난세가 그대로 재현된다.

## 게임의 뼈대

### 한 달의 흐름
1. 도시를 골라 무장에게 **명령**을 내린다 (가능 횟수는 세력 **명성**에 비례)
2. 인접 적성을 노린다면 **출진**으로 군을 낸다
3. `다음 달`을 누르면 — 명령 실행 → AI 세력 행동 → 전투 → 사건 발생 → 달력 진행

### 명령 20종
- **내정** 개간 · 상업 · 치수 · 기술 · 수복 · 순찰 · 시혜
- **군사** 징병 · 훈련 · 고무
- **인사** 등용 · 탐색 · 포상
- **계략** 유언비어 · 이간계 · 매수 · 선동 · 방화 · 첩보

### 전투
전장은 그때그때 생성된다. **진형 8종**(어린·학익·방원·봉시·안행·추행·장사·정란)과
**병과 상성**(기병 > 궁병 > 보병 > 기병)을 살펴야 한다.

- 지력이 높은 무장은 **화계·수계·혼란·매복·함정**을 쓴다 — 바람이 불면 불이 번지고, 비가 오면 꺼진다
- 근접전에서 **일기토**가 벌어진다 (참격·필살·방어·견제 4수 상성, 패하면 부상 또는 전사)
- 공성전에서는 성벽을 두드려 무너뜨리거나 성문을 부수고 진입한다
- 사기가 바닥나면 부대가 무너져 달아난다

### 사람
무장은 저마다 **상성·야망·의리·꿈**을 지닌다.

- 군주와 상성이 맞으면 충성이 오르고, **꿈**을 이루면 목숨을 걸고 따른다
- 야망이 크고 충성이 낮으면 이탈하거나 **모반**해 독립 세력을 세운다
- 등용과 항복 권유는 **설전**으로 겨룬다 (논파·대의·회유·격론 4수 상성)
- 매년 나이를 먹고 성장하며, 수명이 다하면 죽는다. 군주가 죽으면 후계 다툼으로 충성이 흔들린다

## 그래픽

외부 이미지 파일이 **하나도 없다.** 전부 캔버스로 그린다.

- **지도** — 고도를 이중선형 보간해 픽셀마다 채색하고 북서 광원으로 힐셰이딩.
  생태별 질감 붓질(숲 점묘·산 능선·사구·습지), 해안 모래톱, 곡선 하천 4겹,
  성가퀴와 문루 지붕과 망루를 갖춘 성곽 스프라이트, 세력 깃발
- **초상화** — 2배 슈퍼샘플링 후 축소. blur 기반 multiply/lighter 레이어로 입체 명암
  (안와·광대·콧대·턱), 홍채 방사 그라디언트와 이중 반사광, 붓질 머리카락과 수염,
  관·투구 9종, 갑주 미늘, 낙관
- **전투** — 바닥을 흐림 처리해 타일 경계를 녹이고 그 위에 지형 세부를 얹는다.
  날씨(비·눈·안개·강풍)와 야간 연출, 불꽃 애니메이션
- **UI** — 그라디언트만으로 만든 종이결·비단결 질감, 금장 모서리 장식

## 음악

**퍼블릭 도메인 고전 음악 24곡**을 Web Audio API로 실시간 합성한다. 음원 파일 없음.

비발디(봄·겨울) · 바흐(G선상의 아리아·토카타와 푸가) · 베토벤(운명·엘리제를 위하여·월광·환희의 송가·교향곡 7번) ·
모차르트(아이네 클라이네 나흐트무지크·터키 행진곡·라크리모사) · 홀스트(화성) · 그리그(산왕의 궁전에서·아침의 기분) ·
바그너(발키리의 기행) · 차이콥스키(백조의 호수) · 쇼팽(녹턴·장송 행진곡) · 드보르작(신세계로부터) ·
파헬벨(캐논) · 로시니(윌리엄 텔) · 알비노니(아다지오) · 베르디(진노의 날)

- 상황(평시·전투·계략·재해·승리·장례…)에 맞는 곡이 자동으로 걸리고 **크로스페이드**된다
- 악기 14종(현·바이올린·첼로·오르간·하프시코드·피아노·플루트·금관·호른·피치카토·베이스·팀파니·합창·거문고)을
  ADSR + 저역통과 필터 + 비브라토로 합성
- **효과음 30종**도 전부 절차 생성 (칼·화살·북·뿔피리·징·불·홍수·천둥·지진·함성…)
- 배경음악과 효과음 음량을 **각각 조절**할 수 있고, 설정 창에서 24곡을 직접 골라 들을 수 있다

## 단일 파일 빌드

여러 모듈을 하나의 HTML로 묶어 배포할 수 있다.

```bash
node tools/bundle.mjs
```

- `standalone.html` — 완전한 문서. 파일을 브라우저로 바로 열거나 정적 서버에 올리면 된다
- `artifact.html` — 문서 골격 없이 본문만. 아티팩트 등 외부 셸에 삽입할 때 사용

번들러는 `import`/`export` 를 작은 모듈 레지스트리로 바꿔 의존 순서대로 실행한다.
원본 모듈 구조는 그대로 두므로 개발은 `index.html` 로, 배포는 빌드 결과물로 하면 된다.

> `standalone.html` 에는 `<meta charset="utf-8">` 이 반드시 필요하다.
> 없으면 브라우저가 한글을 latin-1 로 읽어 스크립트가 깨진다.

## 저장

`localStorage` 에 6칸까지 기록한다 (한 칸당 약 290KB).

지형은 시드에서 다시 만들어내고 가변 상태만 저장하므로 용량이 작고, **난수열 상태까지 함께 저장**해서
불러온 뒤의 전개까지 완전히 동일하게 이어진다. 브라우저를 닫았다 열어도 유지된다.
