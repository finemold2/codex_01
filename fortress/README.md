# 💣 Fortress — 포격 대전

턴제 포격 게임입니다. 온라인 멀티는 없고, **AI와 대결**하거나 한 기기에서 여러 사람이 번갈아(핫시트) 플레이합니다.
빌드 도구 없이 정적 파일만으로 동작합니다.

## 대전 방식

| 모드 | 설명 |
| --- | --- |
| 개인전 (프리포올) | 2~6명이 각자 살아남기. 1:1, 1:1:1, 1:1:1:1 모두 가능 |
| 2팀전 | A팀 vs B팀. 인원 배분 자유 (2:2, 1:3, 3:3) |
| 3팀전 | A / B / C 세 팀 대결 |

참가자 슬롯마다 **사람 / AI**, **팀**, **전차**를 따로 지정합니다.
사람을 0명으로 두면 AI끼리 싸우는 관전 모드가 됩니다.

## 전차 24종

경장 / 표준 / 중장 / 특수 네 계열로 나뉘며, 체력·장갑·기동력·사거리와 전용 무장 2종이 각각 다릅니다.

- **경장** 코브라, 팔콘, 제피르, 세이버, 아이언벅, 페가수스, 스팅어 — 빠르고 멀리 쏘지만 약합니다
- **표준** 새턴, 볼케이노, 글레이셔, 템페스트 — 균형형
- **중장** 타이탄, 골리앗, 마스토돈, 라이노, 오베론, 워든, 리바이어던 — 단단하고 무겁습니다
- **특수** 스콜피온, 밴시, 하베스터, 미라주, 노바, 크라켄 — 부양 주행, 절벽 등반, 고각 전용 같은 특성을 가집니다

밴시는 부양해서 급경사를 그대로 넘고, 아이언벅은 여섯 다리로 절벽을 기어오릅니다.
스콜피온과 볼케이노는 최소 각도가 높아 곡사 전용입니다.

## 무기 18종

기본탄(무제한) 외에 전차마다 두 종류를 가집니다.

| 무기 | 동작 |
| --- | --- |
| 이중포 · 3연발 · 6연발 | 여러 발이 퍼져 날아갑니다 |
| 클러스터 · 미르브 · 강우탄 | 정점에서 여러 발로 분열합니다 |
| 공중폭발 | 정점에서 공중 폭발합니다 |
| 롤러 | 지면에 닿으면 경사를 따라 굴러갑니다 |
| 굴착탄 | 착탄점에 수직 갱도를 뚫습니다 |
| 지진탄 | 넓은 지형을 통째로 무너뜨립니다 |
| 네이팜 | 불바다를 만들어 3턴간 태웁니다 |
| 빙결탄 | 적을 얼려 다음 턴 이동력을 깎습니다 |
| 연쇄탄 | 착탄점에서 앞으로 3연속 폭발합니다 |
| 방어벽 | 착탄점에 흙벽을 세웁니다 (피해 없음) |
| 순간이동 | 착탄점으로 내 전차를 옮깁니다 |
| 저격탄 | 빠르고 곧게 날아가 큰 피해를 줍니다 |
| 핵탄두 | 단 한 발. 전장을 지웁니다 |

## 아이템 87종

전투를 거듭하며 장비를 모으고, 상점에서 사서 다음 판에 들고 나갑니다.

### 성능이 매번 다르게 굴려집니다

같은 아이템이라도 나올 때마다 수치가 달라지고, 값도 그에 따라 달라집니다.

- **노후 수리 키트** 회복 31 · ◈91  →  **걸작 수리 키트** 회복 50 · ◈122
- **고성능 장약** 사거리 +14% · ◈155  →  **시제 고성능 장약** +19% · ◈194
- **방어막** 2회  →  **걸작 방어막** 3회

품질은 노후 / 표준 / 정밀 / 시제 / 걸작 다섯 단계이고, 등급(일반·희귀·전설·유물)이 높을수록 잘 굴려집니다.

### 지속 방식 세 가지

| 방식 | 설명 |
| --- | --- |
| **일회성** | 탄약·수리 같은 즉시 효과. 쓰면 사라집니다 |
| **이번 판** | 전투 시작과 함께 부착되어 그 판이 끝날 때까지 유지됩니다 |
| **영구 장착 모듈** | 슬롯(4칸)에 꽂아 두면 매 판 자동으로 적용됩니다. 값이 6배 이상 비쌉니다 |

지속 강화 계열은 모듈로도 살 수 있습니다. 모듈은 해체해서 절반값에 되팔 수 있습니다.

### 획득 방법 세 가지

- **보급기** — 몇 라운드마다 수송기가 하늘을 가로지르며 낙하산 상자를 떨어뜨립니다
- **격파 드롭** — 파괴된 전차가 보급품을 남깁니다. 등급이 조금 더 좋습니다
- **보급 상점** — 판이 끝날 때마다 받은 크레딧으로 구매합니다. 재고는 매번 무작위, 재입고도 됩니다

폭발이 상자를 날려버릴 수 있으니 먼저 줍는 쪽이 임자입니다.

### 설명은 마우스를 올리면 보입니다

무기 버튼, 아이템 버튼, 걸린 효과 아이콘, 상점 매물, 창고·모듈 칸,
그리고 **전장에 떨어진 상자**까지 — 마우스를 올리면 등급·품질·지속 방식·수치·설명이 뜹니다.
상자에 마우스를 올리면 화면에서도 점선 테두리로 짚어 줍니다.

### 아이템 갈래

| 갈래 | 예시 |
| --- | --- |
| 탄약 | 핵탄두·미르브·네이팜 등 무기 보급, 무기고 개방(없던 무기 지급) |
| 보급 | 수리 키트, 완전 정비, 증설 차체, 나노 재생, 흡수 장치, **불사조 회로**(1회 부활), **자동 응급 나노** |
| 공격 | 고성능 장약, 증폭 신관, 철갑 탄심, 탄도 컴퓨터(궤적 예측), 관통 탄심, 도탄 장치, 분열 신관, 유도 장치, 과충전, 속사 장전기, 중력 감쇄기, **쌍둥이 포신**, **요새 모드**, **극저온 코팅** |
| 방어 | 증가·복합 장갑, 반응 장갑, 가시 도금(반사), 방어막, 회피 기동, 참호 삽, 급조 방벽, 연막탄, **흡열 장갑**, **방폭 격벽**, **보호 돔** |
| 기동 | 경량 엔진, 등반 갈고리, 예비 연료, 긴급 도약, 고정 앵커 |
| 전술 | 지뢰 매설, **지뢰밭**, EMP, 유막 살포, 무장 교란, 기상 제어기, **폭풍 유발기**, 지각 변동, 유성 소환, 항공 폭격, 산성비, **지형 복원기**, **전장 재배치** |
| 지원 | 아군 수리·재보급, 지휘 통제, 보급 요청 |
| 경제 | 전과 기록기, 자기 수집기, 복제 장치, 전투 보험, **약탈자**, **행운의 부적** |

**사용형 아이템은 전투 중 `Z X C V` 키**로 씁니다. 화면 왼쪽 위에 현재 걸린 효과가 표시됩니다.

## 판 진행 방식

| 모드 | 설명 |
| --- | --- |
| 단판 | 한 판만 겨룹니다 |
| 3판 원정 · 5판 원정 | 연달아 이겨야 완주. 판마다 적 체력·화력이 오르고 AI 실력도 단계별로 올라갑니다 |
| 무한 모드 | 질 때까지 계속. 몇 판을 버텼는지 최고 기록이 남습니다 |

판 사이에는 언제든 상점에 들러 장비를 갖출 수 있습니다.

## 크레딧

판이 끝나면 성적에 따라 크레딧을 받습니다.

참전 수당 · 승리 보너스 · 격파 수 · 누적 피해 · 남은 체력 · 명중률 · 속전속결(빠른 승리) · 판수 보너스를 더하고,
난이도 배율(쉬움 0.75 / 보통 1 / 어려움 1.35)과 아이템 배율을 곱합니다.
지면 40%만 받지만 **전투 보험** 아이템이 있으면 최대 95%까지 지킵니다.

지갑·전적·최고 기록·장착 모듈은 브라우저에 저장됩니다.

## 그 밖의 규칙

- **파괴 지형** — 포탄이 떨어진 곳이 파이고, 발밑이 사라지면 전차가 낙하해 피해를 입습니다
- **바람** — 매 턴 바뀌며 탄도를 휘게 합니다. 화면 상단 화살표로 확인
- **이동력** — 턴마다 제한되고 전차마다 다릅니다. 급경사는 오르지 못합니다
- **턴 제한 시간** — 32초. 시간이 다 되면 현재 설정으로 자동 발사됩니다
- **서든데스** — 16라운드부터 매 라운드 전원 체력이 깎입니다
- **AI 실력** — 쉬움 / 보통 / 어려움. 탄도를 실제로 시뮬레이션해 사격 해를 찾고,
  난이도에 따라 오차가 붙습니다. 아군 오사를 피하고, 막히면 이동하거나 순간이동을 씁니다

### AI의 아이템 판단

무작정 줍지도, 무시하지도 않습니다. 매 턴 이렇게 따집니다.

- **상자 값어치** — 등급·품질에 더해 *지금 나에게* 쓸모가 있는지를 봅니다.
  체력이 멀쩡하면 수리 키트는 거들떠보지 않고, 빈사면 최우선으로 달려갑니다.
  특수탄이 바닥났으면 탄약 상자, 아군이 다쳤으면 지원 상자의 값이 올라갑니다
- **갈 수 있는지** — 연료로 닿는지, 절벽에 막히지 않는지 실제 보행을 미리 굴려 확인합니다.
  못 가는 상자는 포기합니다
- **주울 만한지** — 나보다 가까운 적이 있으면 뺏길 셈 치고 값을 깎고,
  이동 거리와 체력 손실 위험을 비용으로 뺍니다. 남은 값어치가 사격 기회의 손해보다 클 때만 움직입니다
- **한 방이 보이면** — 지금 확실히 격파할 수 있으면 상자는 다음 턴으로 미룹니다

쉬움 AI는 내용물을 모르는 채 어림짐작으로 움직이고, 어려움 AI는 거의 놓치지 않습니다.
사용형 아이템도 상황을 보고 고릅니다 — 멀쩡할 땐 유도 장치, 얻어맞고 있으면 방어막 쪽입니다.

## 조작 (PC)

| 키 | 동작 |
| --- | --- |
| ← → | 이동 · 방향 전환 |
| ↑ ↓ | 포신 각도 |
| Space (홀드) | 파워 충전, 떼면 발사 |
| Enter | 현재 파워로 즉시 발사 |
| PgUp / PgDn | 파워 미세 조절 |

🔊 버튼을 누르면 효과음과 배경음악 볼륨을 따로 조절할 수 있습니다.

전차 선택 화면에서는 방향키로 이동, Enter로 선택, Tab으로 다음 참가자로 넘어갑니다.
이전 사격의 궤적이 점선으로 남아 다음 사격을 조정하기 쉽습니다.

## 그래픽 · 사운드

전부 코드로 만들어집니다. 이미지 파일도, 오디오 파일도, 외부 CDN도 쓰지 않습니다.

- **지형 테마** — 하늘·지층·표면 재질·날씨·광원이 각각 다른 여러 전장
- **전차 아트** — 24종을 Canvas 2D 벡터 드로잉으로 그립니다. 실루엣만으로 구분됩니다
- **폭발 효과** — 코어 섬광, 화구, 연기 기둥, 충격파 링, 파편, 잔불, 화면 흔들림이 겹칩니다
- **효과음** — WebAudio 합성. 무기별 발사음, 폭발 규모별 저역, 금속 타격, 엔진, UI
- **배경음악** — 클래식 18곡을 WebAudio로 직접 연주합니다 (모두 퍼블릭 도메인).
  바흐·비발디·모차르트·베토벤·쇼팽·차이콥스키·로시니·브람스 등. 매 판 셔플로 재생됩니다

## 실행

```bash
# 저장소 루트에서
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000/fortress/
```

`fortress/index.html` 을 브라우저에서 직접 열어도(file://) 동작합니다.
