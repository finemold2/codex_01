# 💣 Fortress — 포트리스 대전

턴제 포격 게임입니다. 온라인 멀티는 없고, **AI와 대결**하거나 한 기기에서 여러 사람이 번갈아(핫시트) 플레이합니다.
빌드 없이 정적 파일만으로 동작하며 `fortress/index.html`을 열면 바로 실행됩니다.

## 게임 모드

| 모드 | 설명 |
| --- | --- |
| 개인전 (프리포올) | 2~6명이 각자 살아남기. 1:1, 1:1:1, 1:1:1:1… 모두 가능 |
| 팀전 (2팀) | A팀 vs B팀. 인원 배분 자유 (2:2, 1:3, 3:3 등) |
| 팀전 (3팀) | A / B / C 세 팀 대결 |

참가자 슬롯마다 **사람 / AI**와 **팀**을 개별 지정할 수 있습니다.
사람을 0명으로 두면 AI끼리 싸우는 **관전 모드**가 됩니다.

## 주요 기능

- **파괴 지형** — 포탄이 떨어진 곳이 파이고, 지면이 사라지면 전차가 낙하합니다(낙하 피해).
- **바람** — 매 턴 바뀌는 바람이 탄도를 휘게 합니다. 상단 화살표로 확인.
- **무기 4종** — 기본탄(∞), 3연발(3발), 대형폭탄(1발), 굴착탄(2발)
- **이동** — 턴마다 제한된 이동력으로 위치 조정. 급경사는 오르지 못합니다.
- **AI 난이도** — 쉬움 / 보통 / 어려움. 탄도 시뮬레이션으로 사격 해를 찾고, 난이도에 따라 오차가 붙습니다.
  아군 오사를 피하고, 필요하면 이동한 뒤 사격합니다.
- **서든데스** — 20라운드부터 매 라운드 전원 체력 감소 (무한 대치 방지)
- **지형 테마** — 초원 / 사막 / 설원 (랜덤 가능)
- **효과음** — WebAudio 합성 (외부 파일 없음, 🔊 버튼으로 끄기)
- **모바일** — 화면 패드로 조작 가능

## 조작

| 키 | 동작 |
| --- | --- |
| ← → | 이동 (방향 전환 포함) |
| ↑ ↓ | 포신 각도 |
| Space (홀드) | 파워 충전, 놓으면 발사 (100 도달 시 자동 발사) |
| PgUp / PgDn | 파워 미세 조절 |
| Enter | 현재 파워로 발사 |
| 1 ~ 4, Tab | 무기 선택 |

이전 사격의 궤적이 점선으로 남아 다음 사격을 조정하기 쉽습니다.

## 실행

```bash
# 저장소 루트에서
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000/fortress/
```

`fortress/index.html`을 브라우저에서 직접 열어도(file://) 동작합니다.

## 구조

```
fortress/
  index.html       화면 셸 (메뉴 / 게임 / 결과 모달)
  css/style.css    다크 테마 UI
  js/
    terrain.js     시드 기반 지형 생성, 크레이터, 테마
    entities.js    월드 상수, 무기, Tank, 발사체 물리/충돌
    sfx.js         WebAudio 효과음
    ai.js          탄도 시뮬레이션 기반 AI (표적 선택·무기 선택·이동·사격 해 탐색)
    game.js        턴 상태 머신, 이동/사격/폭발/낙하, 렌더링
    main.js        메뉴·HUD·입력 바인딩
```
