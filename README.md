# 🌃 NEON CITY — 브라우저 오픈월드 액션 게임

GTA 스타일의 **3D 오픈월드 액션 게임**입니다.
빌드 도구도, 외부 라이브러리도, 에셋 파일도 없습니다. **순수 WebGL2 + Web Audio + ES 모듈**만으로
도시·차량·시민·경찰·총격·클래식 라디오까지 전부 런타임에 생성합니다.

> 저장소 루트를 정적 서버로 열면 바로 플레이됩니다. 설치·회원가입·다운로드가 필요 없습니다.

```bash
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000 접속 → 캔버스를 클릭하면 마우스 조작이 잠깁니다
```

## ✨ 무엇이 들어 있나

### 도시
- **절차적 생성 도시** — 약 1.32 × 1.32 km, **건물 1198동 · 소품 6585개 · 도로 489구간**,
  13개 구역(다운타운 고층 타워 · 미드타운 · 주택가 · 공업지구 · 공원 · 해변)과 17개 랜드마크.
  건물 높이 6.5 m ~ 184 m. 시드 고정으로 매번 동일하며 생성에 0.3초.
- **차선 그래프 기반 도로망** — 방향성 차선 4435개(연결률 99.9%), 우측통행, 교차로 신호 171곳,
  횡단보도, 차선 표시, 대각선 대로.
- **인도 그래프** — 노드 3740개. 시민이 실제로 인도를 따라 걷고 신호를 기다렸다가 건넙니다.
- 모든 배치는 시드 기반이라 **매번 동일한 도시**가 생성됩니다.

### 그래픽 (외부 엔진 없이 직접 구현)
- **물리 기반 렌더링(PBR)** — Cook–Torrance GGX, 금속/거칠기 워크플로, 반구 앰비언트.
- **캐스케이드 섀도 맵** — 텍셀 스냅으로 흔들림 없는 그림자, PCF 소프트 섀도.
- **HDR 파이프라인** — RGBA16F 렌더 타깃, ACES 필믹 톤매핑, 프로그레시브 블룸, SSAO, FXAA,
  비네트·필름 그레인·색수차.
- **대기 산란 하늘** — Rayleigh/Mie 산란, 일출·일몰·밤하늘, 달·별·은하수, 흐르는 구름.
- **밤이 되면 창문에 불이 켜집니다** — 셰이더가 건물 좌표를 해시해 창문 단위로 조명.
- **가로등·헤드라이트·경광등**이 실제 광원으로 동작하는 포워드 라이팅.
- 절차적으로 생성한 텍스처(아스팔트·콘크리트·벽돌·유리 파사드·네온 간판…)와 노멀 맵.

### 게임플레이
- **3인칭 캐릭터** — 뼈대 기반 절차적 애니메이션(걷기/달리기/전력질주/점프/조준/사격/재장전/사망).
- **카메라** — 벽을 피하는 스프링 암, 어깨너머 조준, 차량 추적 시점, 뒤돌아보기, 흔들림, FOV 킥.
- **차량 10종** — 서스펜션 레이캐스트 4륜, 토크 커브 + 자동변속, 슬립 앵글 타이어 모델,
  드리프트, 핸드브레이크, 하중 이동, 충돌 손상과 폭발.
  실측 0→100 km/h: 스포츠카 4.3초 · 스포츠바이크 4.2초 · 경찰차 4.7초 · 머슬카 5.1초 ·
  SUV 6.0초 · 세단 7.2초 · 택시 8.0초 · 밴 9.3초 · 트럭 11.3초 · 버스 11.5초.
- **시민 AI** — 산책·잡담·쇼윈도 구경, 총성에 도망, 차에 치이면 쓰러짐.
- **교통 AI** — 차선 추종, 앞차와 간격 유지, 신호 준수, 경적, 사고.
- **수배 시스템 5단계** — 순찰 → 추격 → 다수 차량 → 도보 경찰·소총 → 최대 경보.
- **무기 7종** — 맨손·권총·기관단총·산탄총·소총·저격총·수류탄. 반동, 탄퍼짐, 헤드샷, 탄피, 탄흔.
- **미션 8종** — 배달, 스트리트 레이스, 청부, 광란, 도주, 호위, 수집, 최후의 저항.

## 🗂 프로젝트 구조

```
index.html              앱 셸 (캔버스 + UI 루트 + 로딩 화면)
css/game.css            전체 UI 스타일
js/
  main.js               부팅 / 로딩 / 메인 루프
  game.js               시스템 조립 · 업데이트 순서 · 카메라 리그 · 헬퍼 API
  missions.js           미션 정의와 상태 머신
  core/                 math · gl(WebGL2 래퍼) · geometry · input
  render/               renderer · shaders · materials · sky · postfx · particles · textures
  world/                citygen(도시 생성) · worldbuild(지오메트리화) · collision
  entities/             player · character · vehicle · ped · traffic · police · weapons
  audio/                audio(그래프) · sfx · music(신시사이저) · scores(클래식 악보)
  ui/                   hud · menu · map
docs/ARCHITECTURE.md    모듈 간 API 계약서
tools/                  헤드리스 검증 스크립트
runclub/                이전 프로젝트(러닝 트래커) — 그대로 보존
```

## 🔧 요구 사항

- **WebGL2**를 지원하는 최신 브라우저 (Chrome / Edge / Firefox / Safari 15+)
- 하드웨어 가속 활성화 권장. 사양이 낮으면 설정에서 품질을 **낮음/보통**으로 변경하세요.
- 오디오는 브라우저 정책상 **첫 클릭(게임 시작)** 이후에 재생됩니다.

## 🧪 개발용 검증

이 프로젝트는 눈으로 확인하는 대신 **헤드리스 크로미움(SwiftShader WebGL2)** 에서 실제로
렌더링하고 측정해 검증합니다.

```bash
node --experimental-vm-modules tools/check-syntax.mjs   # 전 모듈 실제 파싱 (node --check는 ESM 오류를 놓칩니다)
node tools/test-player.mjs                              # 도보 이동/점프/충돌/승하차/피격
node tools/test-collision.mjs                           # 착지·관통·연석·레이캐스트·처리량
node tools/test-vehicle.mjs                             # 10종 0-100km/h·최고속·제동·안정성
node tools/gl-probe.mjs tools/probe-gl.js               # WebGL2 래퍼 (셰이더/인스턴싱/HDR)
node tools/gl-probe.mjs tools/probe-render.js           # PBR·그림자·하늘·품질 프리셋
node tools/gl-probe.mjs tools/probe-world.js            # 도시 생성 → 지오메트리 → 렌더
node tools/gl-probe.mjs tools/probe-audio.js            # 오디오 그래프·효과음·클래식 악보
node tools/gl-probe.mjs tools/probe-game.js             # 게임 전체 부팅 + 조작 + 플로우
node tools/gl-probe.mjs tools/probe-world.js --shot out.png --view aerial   # 스크린샷
```
(브라우저 기반 검증에는 Playwright가 필요합니다: `npm i -D playwright`)
