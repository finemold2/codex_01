# 🧱 TETRIS — 모바일 테트리스

휴대폰 브라우저에서 바로 즐길 수 있는 **터치 최적화 테트리스** PWA입니다.
빌드 도구·프레임워크 없이 정적 파일(Vanilla JS + Canvas)만으로 동작하며, 홈 화면에 설치해 오프라인으로도 플레이할 수 있습니다.

## ✨ 주요 기능

- **게임 모드** — 마라톤(끝까지 버티기), 40줄 스프린트(시간 기록), 2분 울트라(점수 경쟁). 모드별 최고 기록 저장
- **시작 레벨 선택** — 1 / 5 / 10 / 15
- **배경음악(클래식 4곡)** — 코로베이니키(테트리스 테마), 바흐 프렐류드 C장조, 베토벤 엘리제를 위하여, 미뉴에트 G장조. 외부 음원 없이 Web Audio로 피아노·현악·베이스 음색을 합성(배음 + 리버브). 매 판 자동으로 곡이 바뀌거나 직접 선택, 일시정지 화면에서 다음 곡. 레벨·위험·피버에 따라 템포 상승
- **미션** — 게임 중 랜덤 미션 등장(n줄 지우기, 테트리스, T-스핀, 콤보, 홀드 없이 n개, 하드 드롭 8번, 더블 이상 2번). 제한 시간 안에 완수하면 보너스 점수 + 피버 게이지 + 아이템
- **피버 타임** — 라인을 지워 게이지를 채우면 12초간 점수 ×2, 무지개 보드, 음악 가속
- **아이템** — 💣 폭탄(바닥 2줄 제거), ⏳ 슬로우(10초 느리게), 🎯 I 조각(다음 조각 교체). NEXT 아래 버튼 또는 E 키
- **등급** — 게임 종료 시 S/A/B/C/D 등급과 미션 성공·피버 횟수
- **연출** — 라인 클리어 파티클, 테트리스·T-스핀 화면 흔들림, 위험 높이 붉은 경고, 점수 팝업, 레벨 업 플래시
- **터치 제스처** (보드 위)
  - 좌우 드래그 → 한 칸 단위 이동
  - 탭 → 시계 방향 회전
  - 아래로 드래그 → 소프트 드롭
  - 아래로 빠르게 스와이프 → 하드 드롭
- **온스크린 버튼** — ◀ ▶ (누르고 있으면 자동 반복), ⟲ ⟳ 회전, HOLD, ▼ 소프트 드롭, ⤓ DROP 하드 드롭
- **키보드 지원** (데스크톱) — ← → 이동, ↑/X 시계 회전, Z/Ctrl 반시계 회전, ↓ 소프트 드롭, Space 하드 드롭, C/Shift 홀드, E 아이템, P/Esc 일시정지
- **정식 규칙** — 7-bag 랜덤, SRS 회전 + 벽차기, 홀드, NEXT 3개 미리보기, 고스트 조각, 락 딜레이(이동 리셋 15회)
- **가이드라인 점수** — 싱글/더블/트리플/테트리스, T-스핀(풀/미니), 백투백 ×1.5, 콤보, 퍼펙트 클리어, 소프트/하드 드롭 보너스
- **레벨 시스템** — 10줄마다 레벨 업, 가이드라인 중력 곡선
- **피드백** — 토스트(TETRIS! / T-SPIN / COMBO / LEVEL), 효과음(Web Audio), 햅틱 진동
- **설정** — 음악 / 효과음 / 진동 / 고스트 on·off (`localStorage`)
- **자동 일시정지** — 다른 앱으로 전환 시
- **PWA** — 홈 화면 추가, 앱 셸 오프라인 캐시, 세로 모드 고정, 노치(safe-area) 대응

## 🚀 실행 방법

```bash
# 저장소 루트에서
python3 -m http.server 8000
# 휴대폰(같은 Wi-Fi) 또는 데스크톱 브라우저에서 http://<PC IP>:8000/tetris/ 접속
```

## 🗂 프로젝트 구조

```
tetris/
  index.html          앱 셸 / 레이아웃 / 오버레이(시작·일시정지·게임오버)
  manifest.json       PWA 매니페스트
  sw.js               서비스 워커 (오프라인 캐시)
  css/styles.css      다크 테마 UI, 세로/가로 레이아웃
  js/
    tetrominoes.js    7가지 조각, SRS 회전 상태, 벽차기 테이블
    game.js           코어 로직 (보드·중력·락 딜레이·라인 클리어·점수·모드) — 렌더링/입력과 독립
    renderer.js       Canvas 렌더링 (보드, 고스트, 파티클, 위험 효과, HOLD/NEXT 미리보기)
    input.js          키보드 DAS/ARR, 온스크린 버튼, 보드 터치 제스처
    audio.js          Web Audio 효과음
    music.js          Web Audio 클래식 배경음악 (피아노/현악 합성, 4곡 시퀀스)
    missions.js       게임 중 미션 시스템 (렌더링 독립, Node 테스트 가능)
    app.js            UI 조립, 게임 루프, 모드/설정/최고 기록, 미션·피버·아이템·연출
  test/game.test.js   코어 로직 단위 테스트 (node)
```
